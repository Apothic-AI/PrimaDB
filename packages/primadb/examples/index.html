primadb package examples

Browser Examples

These Vite-powered examples consume the local primadb package directly. The threaded example is served with the headers required for SharedArrayBuffer.

Default Notes

Default browser build with IndexedDB segment persistence, byte fields, and blob storage.

/default-notes/

Threaded Mesh

Threaded browser build with mesh replication, optional relay signaling, and the in-page REPL console.

/threaded-mesh/

Binary Stream Room

Browser media chunks written as PrimaDB bytes and replayed from a rolling graph buffer across mesh peers.

/binary-stream-room/

Text + Voice Chat

Text messages and voice chunks both transported through PrimaDB over the shared mesh.

/text-voice-chat/

MoQ Sync

PrimaDB sync envelopes published over a MoQ track with WebTransport-style loopback.

/moq-sync/
