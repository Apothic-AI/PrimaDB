# Local Notes

This example writes notes, bytes, and blobs through the native Python extension and stores them in
a package-local data directory.

## Run

```bash
cd /home/bitnom/Code/gunport/primadb/packages/primadb-python/examples/local_notes
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python main.py
```
